# 🍽️ Tadka Tales
### An Indian Food Discovery and Restaurant Information System

**Har Bite Mein Kahaani**

Tadka Tales is a web-based application developed to explore the diverse food culture of India and help users discover restaurants.

## ✨ Features

- Explore 50+ Indian dishes from North, South, East and West India.
- View dish origins, ingredients, specialities and cultural stories.
- Discover restaurants with images, addresses and contact details.
- View restaurant locations and directions through Google Maps.
- User registration and login.
- Add and remove favourite dishes.
- Contact form for user enquiries.
- Manage application data through the Django Admin panel.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Django
- **Database:** MySQL
- **Database Operations:** Django ORM
- **Database Management:** Django Admin
- **Tools:** VS Code, MySQL Workbench, Git and GitHub

## ⚙️ Installation and Setup

1. Clone this repository:

   `git clone https://github.com/muskananjum315-wq/Tadka_tales`

3. Open the project folder.

4. Create and activate a virtual environment.

5. Install the required packages:

   `pip install -r requirements.txt`

6. Create a MySQL database.

7. Create a `.env` file using `.env.example` as a reference. Add your own database credentials and Django secret key.

8. Apply database migrations:

   `python manage.py migrate`

9. Start the development server:

   `python manage.py runserver`

10. Open `http://127.0.0.1:8000/` in your browser.

## 📌 Project Note

Tadka Tales focuses on Indian food discovery and restaurant information. It does not provide online food delivery.

Developed as an academic project for the Bachelor of Computer Applications (BCA) programme.
